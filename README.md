# homebrew-roomy

Homebrew tap for the [roomy](https://github.com/tdermendjiev/Roomy) CLI: find and free the disk space developer tools and AI agents leave behind.

```sh
brew install tdermendjiev/roomy/roomy
```

`Formula/roomy.rb` is updated automatically by the release workflow of the main repository on every tagged release. Issues and pull requests go to https://github.com/tdermendjiev/Roomy.
